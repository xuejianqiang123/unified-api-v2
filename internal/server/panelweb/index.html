workbuddy WorkBuddy OAuth 注册 / 邀请链接 ↗
1 注册打开邀请链接，用手机号或邮箱登录网页版即完成注册。国内版与国际版是两套账号体系。
2 取凭据「账号」→ WorkBuddy ▾ →「OAuth 登录」→ 选 cn / global →「获取登录链接」→ 浏览器完成登录 → 回到弹窗点「完成登录」。
3 验证账号表出现 WorkBuddy 行，用 auto 发一次对话返回 200。
面板 OAuth 依赖网关同目录的 login.exe；缺失会报 oauth_unavailable。也可命令行：login.exe --realm=cn url 后 poll。
doubao 豆包 Cookie 号池 注册 / 邀请链接 ↗
1 注册打开邀请链接，用手机号登录；网页版或桌面客户端均可。
2 导入（推荐）本机豆包客户端已登录 → 完全退出客户端（Cookie 库有文件锁）→「账号」→ 豆包 ▾ →「导入本机豆包」。
2′ 导入（备用）浏览器登录 doubao.com → 复制完整 Cookie →「账号」→ 豆包 ▾ →「粘贴 Cookie」，填账号名与 Cookie。
3 验证账号表出现豆包行（含积分列）；对话返回 200。
Cookie 等价于账号密码，不要截图或分享。首次对话首字节可能超过 60 秒，属冷启动。
trae TRAE 独立进程 :8000 注册 / 邀请链接 ↗
1 注册打开邀请链接，下载并登录 Trae CN 客户端。
2 起子进程先准备 trae/.venv 依赖并运行 trae\run.cmd；curl http://127.0.0.1:8000/healthz 返回 200 才算就绪。
3 导入本机已登录 Trae 时用「账号」→ Trae ▾ →「导入本机 Trae」；否则「粘贴凭证」填 Cloud-IDE-JWT，或到 Trae2api 网页授权 ↗。
4 验证账号表出现 Trae 行（含积分）；对话返回 200。
网关只做转发，账号与 OAuth 归 trae2api；模型名与别家不同，别名里要用 model_by_provider 映射。
codearts CodeArts（码道） 凭据约 24h 官方入口 ↗
1 注册用华为云账号登录，下载并安装码道 IDE，在 IDE 内登录一次。
2 导入「账号」→ CodeArts ▾ →「从本机 IDE 导入」；或命令行 codearts-import.exe（-check 只看剩余时长）。
3 验证账号表出现 CodeArts 行与额度；对话返回 200。
STS 过期时报 upstream_credential_expired：开一次 IDE 让凭据续期，再导入一次，无需重启。需与 IDE 同一 Windows 用户；takeover 默认关闭（只读复用）。
loomy Loomy Cookie 注册入口 ↗
1 注册打开入口，用手机号 + 验证码登录。
2 登录窗口运行 .\tools\loomy-login.ps1 ，在弹出的独立 Edge 窗口登录，然后关闭整个窗口。
3 导入「账号」→ Loomy ▾ →「导入本机 Loomy」。
4 验证账号表出现 Loomy 行；对话返回 200。
只签发一个 loomy_web_session，失效后需重走登录 + 导入；专用 profile 不影响日常浏览器。
